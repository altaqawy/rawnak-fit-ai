تركيب الإضافة في موقعك

المثال أدناه فعّال للنسخة التجريبية العامة. يلزم API للموافقة على المنتجات قبل اعتماده كتجربة تجارية.

<script defer src="https://altaqawy.github.io/rawnak-fit-ai/sdk/rawnak-fit.js?v=20261118-02"></script>

<rawnak-fit
  store-id="demo-merchant"
  product-id="WATCH-DEMO-01"
  variant-id="silver-42"
  category="watch"
  product-name="ساعة Classic">
</rawnak-fit>

<script>
document.addEventListener("rawnak-fit:add-to-cart", (event) => {
  const { productId, variantId } = event.detail;
  // Your store's own cart function:
  addToCart(productId, variantId);
});
</script>
التكامل التجريبي لا يتحقق من ملكية store-id، ولا يخزن صور العملاء أو يعتمد مجسمات GLB الحقيقية. في المتاجر التجارية هنربط الـSDK بـ API للمتاجر المصرح لها ونمنع استخدام منتجات غير معتمدة. المواقع اللي بتمنع الكاميرا داخل iframe تقدر تستخدم رابط «فتح المراية في صفحة مستقلة».
